## Pytorch explorations and snippets on a local machine with GPU

This mostly came
from [Deep Learning with PyTorch, Second Edition](https://www.manning.com/books/deep-learning-with-pytorch-second-edition)
which I highly recommend this book.

Works on Linux machine with CUDA with usual Google libraries such as absl, glog
and [stile](https://google.github.io/styleguide/pyguide.html).

### Local installation with Pycharm
Add a new Local Interpreter in `venv` directory, sync the project.
